# Changelog

All notable changes to this package will be documented in this file.

## 0.1.0-alpha.0 (unreleased)

First version of `@quantum-ds/penpot`: a Penpot plugin that draws the twenty-five components of `@quantum-ds/components` as Penpot components with variants, one variant per option and state, from the Figma blueprints of `@quantum-ds/figma`, bound to Penpot tokens written from `@quantum-ds/tokens` 2 (the sets Foundation, Component and one per mode, a Light and a Dark theme, references kept), with a progress window built with the design system.
