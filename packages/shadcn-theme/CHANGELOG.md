# Changelog

All notable changes to this package will be documented in this file.

## 0.1.0-alpha.0 (unreleased)

First version of `@quantum-ds/shadcn-theme`: a shadcn/ui theme built from `@quantum-ds/tokens` 2 through shadcn's own theming API, as a stylesheet (`dist/quantum.css`: shadcn's variables on `:root` and `.dark`, the `@theme inline` bridge, the Inter and Fragment Mono fonts and the Quantum radius scale) and as a `registry:theme` item for `shadcn add` (`dist/quantum.json`), every value taken from a Quantum semantic or component token in light and dark, with a demo page (`dist/demo.html`) showing every `new-york-v4` component on the theme.
