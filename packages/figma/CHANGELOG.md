# Changelog

All notable changes to this package will be documented in this file.

## 0.1.0-alpha.0 (unreleased)

First version of `@quantum-ds/figma`: a Figma plugin that draws the twenty-five components of `@quantum-ds/components` as Figma component sets, one variant per option and state, bound to Figma variables recreated from `@quantum-ds/tokens` 2 (one collection per token tier, a Light and a Dark mode, aliases kept), with a progress window built with the design system.
