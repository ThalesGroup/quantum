## 0.1.0-alpha.0 (unreleased)

First version of `@quantum-ds/components`: the specifications of twenty-five components and nine foundations, the JSON Schemas they validate against, their accessibility registry and the platform vocabulary, built on `@quantum-ds/tokens` 2. The package ships the specifications only; the vanilla CSS and HTML reference implementation stays in the repository, where it renders the documentation site.
